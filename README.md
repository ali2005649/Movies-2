## ✨ Features
* **Cross-Platform:** Includes a fully responsive Web application and a native Mobile application.
* **Cinematic UI:** Modern, dark-themed user interface optimized for visual media.
* **Extensive Library:** Discover trending movies, search for specific titles, and view detailed information (Powered by TMDB API).
* **Video Previews:** Integrated video player for movie trailers.
* **Watchlist:** Save your favorite movies using robust backend integration.

## 🛠️ Tech Stack
* **Web:** React, Vite, Tailwind CSS
* **Mobile:** React Native, Expo
* **Backend & Database:** Supabase
* **Data Provider:** TMDB API

## 📁 Workspace Structure

| Directory | Description |
|---|---|
| `/web` | Contains the React + Vite web application. |
| `/mobile/MovieApp` | Contains the React Native + Expo mobile application. |

## 🚀 Getting Started

### 1. Web Application
`cd web`
`npm install`
`npm run dev`

### 2. Mobile Application
`cd mobile/MovieApp`
`npm install`
`npx expo start`
